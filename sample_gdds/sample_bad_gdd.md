# 《星海远征》游戏设计文档(示例·含缺陷)

## 1. 核心玩法

玩家扮演舰队指挥官,通过探索星系、采集资源、组建舰队与其他玩家对抗。
核心循环: 探索 → 采集 → 建造 → 战斗 → 扩张。

## 2. 资源系统

资源分为矿石、晶体、燃料三种。矿石用于建造,晶体用于科技,燃料用于出征。

基础产出: 每座矿场每小时产出矿石若干。产量随等级提升。

## 3. 战斗系统

战斗采用回合制。双方舰队轮流开火,伤害公式: 伤害 = 攻击力 × (1 - 护甲减免)。

护甲减免 = 护甲值 / (护甲值 + 100)。

舰队上限: 每支舰队最多 50 艘战舰。

## 4. 经济与商业化

日产出约 200 水晶(注: 水晶与2.节的晶体是否同一资源,文档未说明)。
月卡售价 30 元,每日领取 60 晶体。

付费可直接购买舰队战力提升包,无购买上限。

## 5. 进度设计

玩家通过升级指挥中心解锁更多建筑与舰船。成长节奏适中,后期曲线陡峭但不失控。

## 6. 新手引导

前 7 天为新手期,期间战斗失败不损失资源。
